# Doku Reader for Kindle

購入済みの電子書籍を、作品・巻ごとに整理して読むためのWindows用アプリです。
開発・サポート：**Dokurock**

**現在はMicrosoft Storeでの販売準備中です。一般向けの販売・ダウンロードはまだ開始していません。**

## アプリについて

- Amazon.co.jpの公式ライブラリから購入済みの蔵書情報を取得。一冊ずつの手入力は不要です。
- 作品・巻ごとにまとめて管理し、分類や作品のまとめ方を編集できます。
- 専用ウィンドウの公式読書画面で読みます。Kindle PCアプリへの事前ダウンロードは不要です。
- 購入日や新刊候補を確認し、本棚と整理した内容を端末内に保存します。

対応環境はWindows 10 build 19041以降／Windows 11、x64、Microsoft Edge WebView2 Runtimeです。Amazon.co.jpのアカウントと通信環境が必要です。海外ストア・オフライン読書は未対応です。

Amazonとは無関係の非公式アプリです。Amazonの判断やサービス変更により、機能の利用やアカウントに影響が生じる可能性があります。対応条件や無料試用・購入の詳細は[サポートページ](https://toku565.github.io/doku-reader-support/support.html)をご覧ください。
