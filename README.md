# Doku Reader for Kindle

**Kindleの蔵書を、自分だけの本棚へ。**

シリーズをまとめる。続巻に気づく。好きな本を、好きな分け方で。
Amazon.co.jpで購入したKindle本の整理から、公式読書画面までをつなぐWindowsアプリです。

**[紹介ページを見る](https://toku565.github.io/doku-reader-support/) · [Microsoft Storeで入手](https://apps.microsoft.com/detail/9N5Q21WB8VS9?hl=ja-JP&gl=JP)**

## 欲しかった6つのことを、ひとつの本棚で

| 困っていたこと | Doku Readerでできること |
| --- | --- |
| シリーズが巻ごとに散らばる | 作品・巻ごとに表示。自分でまとめる・分ける・名前を直す |
| 新刊が出たことに気づきにくい | 更新時に公式ページを確認し、新刊候補を表示。未確認・判定不能も区別 |
| お気に入りが埋もれる | 星を付けた作品だけの表示、お気に入りの上位表示 |
| 自分の分類で分けたい | 分類名を自由に追加して、作品を整理・絞り込み |
| 読む前のダウンロードがひと手間 | 巻の表紙から専用ウィンドウの公式読書画面へ。Kindle PCアプリへの事前ダウンロード不要 |
| 完結した作品を見分けたい | 自分で完結マークを付け、完結・未完結で絞り込み |

新刊は利用者が更新を行ったときの確認結果です。発売の常時監視・自動通知ではありません。完結は手動の印で、連載状況の自動判定や読了とは異なります。

## 無料で150冊から

150冊まで、期間の制限なく取得・表示・検索・整理・公式読書を試せます。
製品版は **1,000円（税込）の買い切り**。購入後に「本棚を更新」で残りの蔵書を取得できます。
最新の価格・提供条件はMicrosoft Storeでご確認ください。ダウンロードと購入はMicrosoft Storeで行います。

## 対応環境

Windows 10 build 19041以降／Windows 11、x64、Microsoft Edge WebView2 Runtime。
日本のAmazon.co.jpアカウントとKindle for Webの利用環境、インターネット接続が必要です。読書時の通信・キャッシュは発生します。海外ストア・オフライン読書は未対応です。

Amazonとは無関係の非公式アプリです。Amazonの判断やサービス変更により機能の利用やアカウントに影響が生じる可能性があります。対応形式・アクセス状況により、すべての蔵書や新刊を確認できるとは限りません。
